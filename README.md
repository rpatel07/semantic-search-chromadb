# Semantic Search with ChromaDB

This project is an improved version of my semantic search project. Instead of using NumPy to search through embeddings, I used ChromaDB to store documents and find relevant results based on their meaning.

### What I learned
- Using ChromaDB as a vector database
- Generating embeddings with Sentence Transformers
- Searching documents using cosine distance
- Storing documents and metadata in a JSON file
- Implementing basic operations to insert, retrieve, search, and delete documents

### Tech Stack
Python, ChromaDB, Sentence Transformers, JSON

This project helped me understand how vector databases can be used to build semantic search applications.
